# Simple Interest Calculator

A simple Python program to calculate **Simple Interest** using user input.

## 📌 Formula

Simple Interest is calculated using:

SI = (P × R × T) / 100


Where:
- **P** = Principal Amount
- **R** = Rate of Interest
- **T** = Time Period

---

## 🚀 Features

- Takes user input
- Calculates simple interest instantly
- Beginner-friendly Python program

---

## 🖥️ Example Code

```python
principal = float(input("Enter Principal Amount: "))
rate = float(input("Enter Rate of Interest: "))
time = float(input("Enter Time Period: "))

simple_interest = (principal * rate * time) / 100

print("Simple Interest =", simple_interest)
